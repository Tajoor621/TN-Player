Browser player

Play a local file

Choose video or audio from this device, or drop it on this page. The file stays in this browser tab and is never uploaded. TN-Player does not send it to a server or add it to a cloud library.

You can choose more than one file. A new selection replaces the queue, up to 100 files. The queue below is what plays. A WebVTT or plain SRT file in the same selection is used as captions.

Captions stay in this tab. Styled ASS and SSA files are not rendered here. The Android app has separate subtitle support.

Playback options
    Keyboard shortcuts
    • Space or K plays or pauses when focus is not on a control or the video
    • Left and Right seek 10 seconds
    • M mutes, F toggles full screen
    • N plays the next file, P the previous file

    The video controls keep their own keys while that control is focused. The Android app supports 0.25× to 4×. This page offers the speeds above.

    Resume position for the same file name, size, and modified time is stored in this tab only and cleared when the tab closes. Playback formats depend on your browser. For Media3, direct streams, and more formats, install the Android app.
