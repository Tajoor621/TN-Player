# Corrections applied to the supplied master prompt

1. **Permissions do not confer root access.** Ordinary apps cannot use platform-signature permissions such as CAPTURE_AUDIO_OUTPUT, MODIFY_PHONE_STATE, SET_TIME or DUMP as if they were runtime grants. They are not declared. Phone, microphone, camera, location, NFC, usage tracking, overlays and install/billing permissions are also omitted because this core has no feature requiring them. Official reference: https://developer.android.com/reference/android/Manifest.permission
2. **Storage:** a player can use MediaStore for a permission-gated library and SAF for user-selected documents. MANAGE_EXTERNAL_STORAGE does not unlock all protected app directories. Android 11+ also restricts selectable tree roots and Android/data/obb. This build uses SAF and media permissions; it does not claim unrestricted/root access. https://developer.android.com/training/data-storage/shared/documents-files and https://developer.android.com/about/versions/11/privacy/storage
3. **FFmpegKit:** the original `com.arthenica:ffmpeg-kit-full:6.0-2` line is not a sustainable default; the upstream project says it is retired. A maintained source continuation exists, but has not been integrated or audited here. FFmpegKit command execution does not itself add a universal ExoPlayer video renderer. https://github.com/arthenica/ffmpeg-kit and https://developer.android.com/media/media3/exoplayer/supported-formats
4. **PiP:** `android:autoEnterPictureInPicture` and `android:pictureInPictureParams="@xml/pip_params"` in the sample are not valid Activity manifest attributes. The Activity declares support; runtime PictureInPictureParams configure ratio/auto enter with API guards. https://developer.android.com/develop/ui/views/picture-in-picture
5. **Background playback:** one MediaSessionService owns one player. Media3 coordinates audio focus, noisy events, media notification and session controllers. A duplicate PlaybackService plus NetworkStreamService is unnecessary for the same engine. START_STICKY or battery exemptions cannot guarantee survival after force-stop or OEM termination. https://developer.android.com/media/media3/session/background-playback
6. **Widgets are broadcast receivers**, typically AppWidgetProvider, not content providers. https://developer.android.com/develop/ui/views/appwidgets
7. **USB:** `android.permission.USB_PERMISSION` is not a general Android permission. Use a package-scoped PendingIntent action for UsbManager.requestPermission, or access exposed storage through a document provider. https://developer.android.com/develop/connectivity/usb/host
8. **Container ≠ codec ≠ DRM entitlement.** An MKV container may contain codecs unavailable on a given device. Atmos and TrueHD require supported decoding/passthrough and output paths. M4P and other protected files may require rights and an appropriate DRM integration. No “play everything” guarantee is made.
9. **Telemetry consent:** this build has no analytics SDK. A future Firebase variant must disable collection before initialization until the user consents. No duplicate Analytics integration or fabricated cloud keys are shipped.
10. **Build and shrink rules:** pinned compatible dependencies, a real Gradle wrapper, and library consumer R8 rules replace blanket class keeps. No native binaries are bundled, so redundant ABI splits are not enabled. The supplied min/target/version remain intact.
11. **Local storage paths:** use `filesDir`, `cacheDir` and `getExternalFilesDir`, not hardcoded `/data/data/com.tplayer`, which also differs from the supplied package name.
12. **Performance:** startup, battery and seek thresholds require measured baselines and test-device definitions. They cannot be guaranteed by Gradle or a manifest.

These links were reviewed to guide the implementation. Their latest contents may evolve independently from this pinned baseline.
