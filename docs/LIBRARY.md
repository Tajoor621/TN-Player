# Library follow-up (source-only)

This branch implements the third planned feature prompt. It leaves the previously published APK and Pages download unchanged; its changes are not on main until reviewed and merged.

- **Sort:** Indexed folders remember their sort and direction independently. View and layout at the tab root still edits the global default. A folder with no override inherits the existing global settings; the SAF Files browser retains its current ordering. A folder that is moved or renamed has a new index identity.
- **Search:** Videos and Music keep their own “Search all folders” switch for the current UI session. With a nonblank query the switch searches accessible files across all indexed folders of the current media type, using the existing paging and filters. With the switch off, the field still searches the current listing. Blank input restores browsing. Result refreshes do not replace the search field.
- **Continue watching:** The top-level Videos tab shows up to ten recent local videos with known duration and a resumable position. Audio, network sources, unknown-duration items and files in the existing final-three-seconds completion window are excluded. The row is hidden when empty. A row tap explicitly requests the saved position, independent of automatic resume.
- **Matching subtitles:** The Subtitle menu lists up to 24 matching files from the current folder (scan up to 5,000 siblings). A case-insensitive exact basename can be followed by a language tag, with optional script and region (such as `en`, `pt-BR` or `zh-Hant-TW`). Supported extensions are SRT, VTT, MPL, PJS, SUB, TXT, ASS, SSA, TTML and DFXP; format and encoding checks are shared with manual imports. Auto-selection is off by default and prefers an untagged match, then the format and filename ordering. A manually restored timed caption takes precedence. Discovery is canceled when the player stops or changes files. It uses readable file paths and local external-storage SAF grants; a single-file grant, MediaStore permission without a matching folder grant on Android 10+, or an opaque provider does not grant sibling access.
- **Playlist rename:** Trims names, rejects blank/control-character names and names already used by another list (ignoring case and outer whitespace), and updates the existing row in a Room transaction. It does not rewrite legacy playlists or change the database schema.

## Settings and backup compatibility

`libraryFolderSort_<sha256>` stores a sort ordinal and a 0/1 descending flag as `ordinal:flag`, keyed by the indexed volume and relative folder path. The existing `librarySort` and `libraryDescending` stay as the global default; no preference is overwritten on upgrade. Up to 512 folder overrides are kept and merge-restored, with deterministic eviction at the cap. Invalid keys, types and out-of-range orders are rejected on backup import. `autoMatchingSubtitles` is a backed-up Boolean, default false; older backups can omit it. Backup format remains version 1, and Room remains schema 2.
